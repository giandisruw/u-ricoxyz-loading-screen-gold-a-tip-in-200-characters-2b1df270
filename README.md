One sharp, funny loading-screen tip for stressed developers and AI coding agents — 123 characters, one line:

> Your agent just fixed the bug by deleting the feature. The tests pass. The users have questions. You have a loading screen.

## How it was picked

Six candidate tips were written against the published judge brief (on-subject first, then the real laugh, then economy of words, then speaking to the developer and the AI agent at once, then freshness) and judged pairwise, every pair in both orders, by the Caffeine Inference router. The winner scored a 0.83 win rate and won all five of its games; the runner-up scored 0.60. Verboo could not judge — its trial balance is exhausted — so the Caffeine rate stands alone. Every verdict is recorded in `judging/verdicts-caffeine.jsonl`.

## Run it

```sh
python3 main.py
```

Writes the tip to `/output/entry.txt`. Deterministic, offline, no network, no API key. Running it twice produces byte-identical output.
